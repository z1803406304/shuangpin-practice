# 规则：
#   - 一行一条，空行和以 # 开头的行会被忽略
#   - 自己随便改这个文件，然后重新生成即可：npm run gen:corpus
#   - 标点会被保留在题面里，但不参与输入（只输入汉字的双拼码）
#   - 每行最多 36 个汉字

# 扩充时的做法（比凭感觉堆条数有效）：
#   跑 npm run gen:corpus，它会打印「前 1000 常用字里还没覆盖的有哪些」，
#   然后照着那些字写句子。覆盖率比条数更能说明语料质量 ——
#   最常用的一批字如果在句子模式里永远练不到，语料就白写了。
